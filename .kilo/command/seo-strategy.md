# /seo-strategy — SEO Content Strategy Planner

Generates an evidence-backed content strategy plan for a target keyword or topic cluster
aligned with the BestAIAgent.in SEO Growth Engine v2.0 and the 100-page topical authority map.

## Usage

```
/seo-strategy [topic]
```

## What This Does

1. **Search intent analysis** — Identifies whether the query is informational, transactional,
   commercial, or comparison-based.
