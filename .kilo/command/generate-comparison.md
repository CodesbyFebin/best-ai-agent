# /generate-comparison — Evidence-Backed Comparison Generator

Generates a comparison draft between two AI agents/companies following the BestAIAgent.in
content lifecycle, Safe-Deep evidence schema, and editorial quality standards from `AGENTS.md`
and `.kiro/steering/content.md`.

## Usage

```
/generate-comparison [agentA-slug] [agentB-slug]
```

Example: `/generate-comparison cursor-ai claude-code`
