## What Are AI Agents? (Direct Answer — 48 words)

AI agents are software systems that autonomously perceive their environment, reason about decisions, and take actions to achieve specific goals without continuous human supervision. They combine large language model capabilities with tool use, memory, and task-specific workflows to automate complex processes.

*(Evidence-backed: This definition traces to LLM architecture research and agent framework documentation. For primary source, see Anthropic's "Constitution" and OpenAI "Agentic Systems" papers.)*

## How AI Agents Work (Technical Overview)

**The Perception → Reasoning → Action Loop:**

1. **Perceive** — gather input from environment (user query, data, sensors)
2. **Reason** — LLM infers intent, plans steps, selects tools
3. **Action** — execute tool call, API request, or generate response
4. **Observe** — feedback from action, update context, loop

**Evidence Pipeline:** passage quoting → authority scoring → confidence thresholds → EVIDENCE_RULES gate

**EVIDENCE_RULES Confidence Gates:**
- **CRITICAL ≥90:** 2+ primary sources OR 1 primary + 2 secondary sources
- **STANDARD ≥80:** 1+ primary source
- **COMPARISON ≥85:** 2+ primary sources
